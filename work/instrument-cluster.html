At a glance

  • Production C++ and Qt/QML software for Hyundai commercial-vehicle instrument clusters, built from Hyundai/Mobis specifications.
  • CAN/LIN signal handling and HMI behavior in a Yocto-based environment.
  • Verification through simulation, physical devices, GoogleTest unit tests, CI and on-vehicle testing.

Outcome

Host-side test automation reduced a manual workflow that previously took several days to approximately two hours.

The problem

An instrument cluster's behavior is defined by detailed specifications and has to be checked across many vehicle configurations. Checking them by hand took days.

What I did

  • Develop production C++ and Qt/QML software from Hyundai/Mobis specifications, including CAN/LIN signal handling and HMI behavior.
  • Perform simulation and physical-device verification, GoogleTest unit testing, CI-based validation, defect reproduction and on-vehicle testing.
  • Review and resolve static-analysis findings with QAC and CodeSonar for MISRA/CWE-related compliance and maintainability.
  • Built host-side test automation that drives a physical cluster over ADB.
