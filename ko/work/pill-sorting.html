프로젝트 요약

  • 고해상도 앞면과 뒷면 이미지 쌍으로 초기 약 16종의 알약을 인식합니다.
  • 프로젝트 전용 이미지로 학습한 CNN 분류기로 시작했으며, 이후 DINOv2 기반 시각 표현을 평가했습니다.
  • 신뢰도가 낮은 예측은 자동 분류하지 않고 수작업 처리 대상으로 분리합니다.

결과

알약 인식 결과를 로봇 분류 컨트롤러와 연동했으며, 새로운 알약 종류를 추가할 수 있는 재학습 절차를 구축했습니다.

해결하고자 한 문제

분류 로봇은 비전 시스템의 판단에 따라 동작합니다. 알약을 잘못 분류하는 비용이 판단을 보류하는 비용보다 크다고 판단했기 때문에, 시스템의 신뢰도가 낮을 때 안전하게 자동 분류를 보류하는 방법이 필요했습니다.

제가 맡은 역할

  • 앞면·뒷면 이미지 쌍을 위한 시각 인식 파이프라인을 개발했습니다.
  • 프로젝트 전용 이미지 데이터로 초기 CNN 분류기를 학습시켰고, 이후 개발 단계에서 DINOv2 기반 표현을 평가했습니다.
  • 신뢰도에 따른 자동 분류 보류 규칙을 설계했습니다.
  • 분류 결과를 로봇 분류 컨트롤러와 연동하고, 시스템 전체를 다시 설계하지 않고도 새 알약 종류를 추가할 수 있는 재학습 절차를 만들었습니다.

시스템 구성과 동작 원리

시스템을 단순화한 개념도입니다. 각 구성 요소를 선택하면 설명을 볼 수 있습니다.

공개 가능한 프로젝트 정보를 바탕으로 구성한 개념도이며 실제 제품 설계도는 아닙니다.

자동 분류 또는 보류

신뢰도 임계값을 조절해 보세요. 기준보다 높으면 자동 분류하고, 나머지는 수작업 처리로 넘깁니다. 이 가상 예시에서는 기준을 높이면 자동 분류 건수와 오분류 건수가 모두 줄어듭니다.
