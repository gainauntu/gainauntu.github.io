GT System, 용인

담당 역할
연구원

프로젝트 요약

  • 현대자동차·현대모비스 사양을 기반으로 현대 상용차 계기판용 양산 C++·Qt/QML 소프트웨어를 개발합니다.
  • Yocto 기반 환경에서 CAN/LIN 신호 처리와 HMI 동작을 구현합니다.
  • 시뮬레이션, 실제 장비, GoogleTest 단위 테스트, CI, 실차 시험으로 검증합니다.

결과

호스트 측 테스트 자동화로 기존에 며칠 걸리던 수작업을 약 두 시간으로 단축했습니다.

해결하고자 한 문제

계기판의 동작은 세부 사양으로 정해져 있고, 수많은 차량 설정 조합에서 모두 확인해야 합니다. 이를 손으로 확인하면 며칠이 걸렸습니다.

제가 맡은 역할

  • 현대자동차·현대모비스 사양을 바탕으로 CAN/LIN 신호 처리와 HMI 동작을 포함한 양산 C++·Qt/QML 소프트웨어를 개발합니다.
  • 시뮬레이션·실장비 검증, GoogleTest 단위 테스트, CI 기반 검증, 결함 재현, 실차 시험을 수행합니다.
  • MISRA/CWE 관련 요구사항 대응과 유지보수성 개선을 위해 QAC·CodeSonar 정적 분석 결과를 검토하고 문제를 해결합니다.
  • ADB로 실제 계기판을 제어하는 호스트 측 테스트 자동화를 구축했습니다.

시스템 구성과 동작 원리

시스템을 단순화한 개념도입니다. 각 구성 요소를 선택하면 설명을 볼 수 있습니다.

공개 가능한 프로젝트 정보를 바탕으로 구성한 개념도이며 실제 제품 설계도는 아닙니다.

주요 구현 내용

사양에서 HMI까지

Yocto 기반 환경에서 완성차 사양을 바탕으로 신호 처리와 HMI 동작을 C++·Qt/QML로 구현합니다.

여러 단계의 검증

GoogleTest 단위 테스트, CI 검증, QAC·CodeSonar 정적 분석, 시뮬레이션, 실장비, 실차 시험으로 확인합니다.

설정별 테스트 자동화

호스트 측 도구가 수백 개의 차량 설정을 적용하고 테스트를 실행한 뒤, 캡처한 화면을 판정해 보고서를 만듭니다.
