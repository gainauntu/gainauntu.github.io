Automated Water Intake & Pump Control System자동 취수 및 펌프 제어 시스템

소속
Approtec
기간
2023년 6월 – 2024년 6월
담당 역할
임베디드 소프트웨어, 펌프 제어, 모니터링

프로젝트 요약

  • 인공함양 시스템의 취수를 감시하고 제어하는 Raspberry Pi 기반 소프트웨어입니다.
  • 수위·유량 센서 값을 RS-485로 읽어 실시간으로 수집하고 표시합니다.
  • 펌프 자동 제어, 권한별 접근을 지원하는 Qt 대시보드, MySQL과 Google Cloud SQL 기반 데이터 관리.

결과

RS-485로 수위·유량 데이터를 수집하고, 펌프를 자동 제어하며, 권한별 Qt 대시보드로 모니터링과 제어를 제공하는 Raspberry Pi 소프트웨어를 구현했습니다. 데이터는 MySQL과 Google Cloud SQL로 관리합니다.

해결하고자 한 문제

인공함양 시스템은 물을 끌어들여 펌프로 보냅니다. 수위와 유량을 계속 감시해야 하고, 펌프는 사람이 직접 조작하지 않아도 동작해야 합니다.

고객사, 설치 장소, 하드웨어 모델, 운전 설정값은 공개하지 않습니다. 이 페이지의 그림과 시뮬레이션은 개념 설명용입니다.

제가 맡은 역할

  • Raspberry Pi 기반 임베디드 소프트웨어를 개발했습니다.
  • 수위·유량 센서와의 RS-485 통신과 실시간 데이터 수집을 구현했습니다.
  • 펌프 자동 제어 기능을 구현했습니다.
  • 권한별 사용자 접근을 지원하는 Qt 모니터링·제어 대시보드를 만들었습니다.
  • 로컬 데이터는 MySQL로 관리하고 Google Cloud SQL과 연동했습니다.

시스템 구성과 동작 원리

시스템을 단순화한 개념도입니다. 각 구성 요소를 선택하면 설명을 볼 수 있습니다.

공개 가능한 프로젝트 정보를 바탕으로 구성한 개념도이며 실제 제품 설계도는 아닙니다.

취수 설비 하루 운전해 보기

가상의 취수조와 가상 데이터로 구성한 시뮬레이션입니다. 유입량을 바꾸고 자동·수동 제어를 전환하며, 대시보드에서 운영자와 조회 사용자가 각각 할 수 있는 일을 확인해 보세요. 모든 내용은 예시입니다.

가상 데이터로 구성한 예시 시뮬레이션입니다. 수위, 유량, 제어 설정은 임의로 정한 값이며, 실제 프로젝트의 하드웨어, 설정 또는 결과를 나타내지 않습니다.
